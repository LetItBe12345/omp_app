# MVP-08：文件树、文件搜索与上下文引用

- 状态：已完成
- 优先级：P1
- 前置任务：MVP-07
- 后续任务：MVP-09

## 目标

提供浏览 Workspace、搜索文件和引用本地上下文所需的最小文件能力。

## 完成内容

- 文件树逐级懒加载。每个目录独立分页，每页 100 项，目录在前并自然排序。
- 文件树显示点文件和忽略项；文件搜索复用 Git CLI 和 `ignore` 包的忽略规则。
- 大目录读取、排序和分页由 Node Worker Thread 执行，单次读取超时 5 秒。
- 根目录和展开目录使用非递归 `fs.watch`，支持目录冷却、校正刷新、并发限制和 256 个 watcher 上限。
- 总刷新按新修订号重新读取根目录和当前可见展开目录，保留旧内容直到新分页全部取得。
- 文件树使用 `@tanstack/react-virtual`，支持单选、方向键、Enter、菜单键、分页和滚动锚点。
- 搜索延迟 120 毫秒，最多显示 100 个按四级规则排序的文件和目录结果。
- 文件、目录和根节点可以拖入 Composer 或通过精确的右键菜单加入上下文。
- 内部拖拽携带 Workspace ID，切换 Workspace 后拒绝旧数据；加入前统一由 Main 校验和去重。
- Tool Call 只读取已知写文件工具的结构化路径，成功结束后使对应目录失效；不解析 Bash 或文本。
- Markdown 文件链接和整段行内代码路径由 Main 校验，支持 URL 编码、`~/` 和四种行列后缀。
- 本地路径和 HTTP(S) 链接仅响应平台修饰键点击或修饰键加 Enter。
- Workspace 切换和应用退出会取消搜索、队列与请求，并关闭 watcher 和 Worker。
- 文件树调试日志只记录 Workspace ID、相对路径、数量、耗时和触发来源。
